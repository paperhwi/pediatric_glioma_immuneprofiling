# Follow-up execution details

The executed core versions match the recorded original analysis versions: pandas 2.3.3, NumPy 2.5.3, SciPy 1.18.1, scikit-learn 1.9.1 and lifelines 0.30.3. The follow-up used Python 3.12.14; the original pipeline recorded Python 3.13.18. Full environment metadata is in `environment.json`.

Clustering assignments: k3; seeds 42–66; B 500; 80% sampling without replacement; KMeans n_init10; average linkage of 1-consensus; names by ordered mean T-cell cytotoxicity; per-participant modal labels. Both matrices use the same sample order. New scaling uses mean 0/sample SD 1 within343 (ddof 1), not signature re-scoring. K diagnostics retain the original B 1000/n_init 1/seed 42 settings; gap uses 50 PCA-rotated uniform references and KMeans n_init10.

Survival models: corrected OS; molecular group (pHGG_WT reference), age in years, male (female reference); fixed all-cohort SD of the existing 21-program axis. Library is four categories, poly-A stranded reference, or separate baseline-hazard strata. All fits are unpenalized with Efron ties. Wald 95% CIs and two-sided P values are reported. Nested LRTs use identical rows and strata. PH rank-time diagnostic P values are unadjusted. Partial likelihoods/AICs across different stratification structures are not directly compared.

## Restricted input schema

`PGI_RESTRICTED_SURVIVAL_INPUT` points to an authorized TSV outside this Git checkout, one row for each of the343 public biospecimen IDs, with the ID in the first/index column. Required columns:

| Column | Meaning |
|---|---|
| `OS_days_corrected` | Diagnosis-origin audited duration in days |
| `OS_event` | Death1/censoring0 |
| `OS_corrected_record` | Boolean, the four uniformly re-timed records |
| `in_survival_analysis` | Boolean eligibility flag |
| `age_at_diagnosis_years` | The same diagnosis-age covariate as the original corrected-OS fit |
| `sex` | Female/Male for the245 evaluable records |
| `autopsy_specimen` | Boolean specimen flag |
| `molecular_group` | Original four-group code |
| `RNA_library` | Original library category |
| `immune_axis` | The fixed published n343 axis |

The connector checks exact ID membership/order and concordance with the public group/library/axis annotations. The fitting script verifies the original baseline estimate before reporting library-controlled results. Derive corrected outcomes using the original uniform audit; do not substitute released durations. Boolean fields must parse as true/false or 0/1.

Private generated files default to `.n343_private_outputs` beside the input. `PGI_RESTRICTED_OUTPUT_DIR` may point to another external directory. Individual design matrices and event-time residuals remain outside Git. Running the independent Efron verification requires that private design generated by the survival script.
